Terminal D Operations Briefing (TDOP) — Quick Start Guide

Gate Gadget Initiative  ·  DFW Terminal D  ·  Internal Use Only

TDOP V1.0.3
Created by Brad J. Sapit
TDOP is DFW Terminal D's live operations briefing tool. It pulls flight data directly from the Stand & Gate API, displays Terminal D and F-Hardstand ops side-by-side, tracks real-time gate changes, and sends formatted briefings to every ops team — all in one browser tab.

Toolbar Buttons

Generate

Fetches live data for the selected date & shift window. Always your first action.

📄 PDF

Exports the full briefing grid as a formatted PDF including ETAs, notes, and pax.

✉ All Ops

Opens mail pre-addressed to all ops distribution lists with full briefing HTML.

🟣 HS Ops

Hardstand-only brief to Gate Control / HS leadership.

🟢 LF Ops

Frontier (F9) scoped brief to Menzies F9 ops team.

🌐 INTL Ops

Email + Teams card for INTL ops (13:00–21:00 filter, Power Automate).

🔴 Swiss

Swiss / Swissport scoped brief to DFW OCC.

🔵 WFS

WFS scoped brief to WFS DFW OCC.

🚌 Bus Board

Bus gate board for D5 & D7 bus station flights.

👁 Prospect

Scoped brief for Prospect handler flights.

📋 Traffic

Generates a Traffic list for all arrivals within the current TDOP shift window.

🌙 O/N Traffic

Overnight Traffic list — fixed 21:00–08:00 window, filters arrivals to designated O/N stands only (D6, D8A, D10–D16X, T83–T93). Independent of the shift window picker.

👁 SeeSay

Automatically posts a Teams adaptive card in the Bussing chat prompting staff to use the SeeSay app for IOC requests. Includes a direct link to the mobile app.

🔧 Equip

Opens Ground Equipment Notification form.

☀️/🌙 Theme

Toggle light / dark display mode.

🗑 Clear All

Wipes all state, ETAs, notes, and flags. Use at end of shift.

Airline Card Anatomy

Qatar Airways · QR
⚠ Gate Changed GATED
ARR QR 739 D-16 STA 14:35 ETA 14:52
DEP QR 740 D-16 STD 16:15 pax: 289
①

Header bar — airline name + IATA. Amber ⚠ when gate/pad changed; green GATED when on hold.

②

ARR / DEP rows — flight number, gate, STA/STD (crossed out when ETA entered), and ETA/ETD in orange.

③

Pax field — enter expected pax count per leg. Carries into all exports.

④

✗ Cancel checkbox — strikes the leg red. Both legs cancelled → card moves to terminal section.

⑤

Note field — per-leg free text (up to 100 chars). Appears in PDF and email exports.

Shift Start Workflow

1

Set Date & Shift Window in the header. Unlock date if locked from prior session.

2

Click Generate. Status dot turns green; hardstand (left) and terminal (right) cards populate.

3

Enter ETAs / ETDs — click any ETA/ETD cell and type time. Overrides STA/STD in all exports.

4

Add Notes & Pax — per-leg fields. Both appear in PDF and email.

5

Flag Cancellations — check ✗ on cancelled legs.

6

Send Briefings — All Ops for full blast; individual buttons for targeted sends.

7

End of shift: Click 🗑 Clear All to reset for incoming coordinator.

Key Features

⚠️
Gate/Pad Changed badge — amber flag when the API detects a reassignment. Hover the highlighted cell to see the original value.
💾
Auto-save — every input saves instantly to local storage. Restore any time with Load Saved.
🔴
+1 Next-Day badge — appears on times crossing midnight so you know it's the following calendar day.
🃏
Gated toggle — dims a card and strikes through fields to flag an aircraft on hold or blocked at gate.
📋
Multi-select toolbar — check two or more airline cards to batch-export or email only those flights.
🔓
Date lock — date field locks after Generate to prevent accidents. Tap 🔓 to unlock if you need to re-generate.
🌐
INTL Ops = dual send — fires email AND a Power Automate Teams card simultaneously. 13:00–21:00 STA/ETA filter applied.
🚌
Bus Board — built from existing briefing data for D5/D7 bus station flights. No extra entry needed.
🔧
Equipment button — opens Ground Equipment Notification form. Select handler, add equipment + location, send formatted email.
⏰
Baseline resets at 3:00 AM nightly and on Clear All — gate-change flags start fresh each day.
🌙
O/N Traffic — fixed 21:00–08:00 window, filters to designated overnight stands only (D6, D8A, D10–D16X, T83–T93). Independent of the shift window picker. One-click overnight report — no settings adjustment needed.
👁
SeeSay — automatically posts a Teams adaptive card in the Bussing chat directing staff to submit IOC requests via the SeeSay app. Includes a direct mobile link. No briefing required — always available.
