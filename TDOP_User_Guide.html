1 — What Is TDOP?

TDOP (Terminal D Operations Briefing) is the primary web tool within the Gate Gadget Initiative, created by Brad J. Sapit for DFW Terminal D gate coordinators and supervisors. It fetches live flight data from the Stand & Gate API, presents Terminal D gate flights and F-Hardstand operations in a side-by-side briefing grid, and provides one-click email and Teams actions to communicate the shift picture to every relevant ops team.

Live Data & Auto-Refresh

Briefing data pulled live from the Stand & Gate API each Generate and auto-refreshed on a timed cycle. Gate and pad reassignments are detected each cycle and flagged with an amber ⚠ badge.

Two-Column Briefing Grid

Left column: F-Hardstand operations. Right column: Terminal D gate flights. Each airline gets its own card with arrival and departure rows, inline editable fields, and per-leg controls.

Cloud Save & Live Sync

Every ETA, ETD, pax count, note, cancellation flag, and gated state can be saved to shared cloud storage with 💾 Save. Typed entries also save automatically about 8 seconds after you stop typing, and other machines running the same day pick up changes within 10 seconds. Click ↓ Load (or Load Saved on startup) to restore.

Email & Teams Sends

Full-briefing and scoped emails from the Send Report menu, plus live Teams posts — Bus Needed, Alert I / II / Terminated, SeeSay, Intl Ops, and selected-card posts — all from the same toolbar. A hardstand snapshot also publishes to BusBoard automatically.

3 — Airline Card Controls

Each airline card contains inline controls per flight leg plus card-level controls in the header.

ControlWhat It Does
ETA / ETD FieldClick the ETA or ETD cell and type the estimated time (e.g. 14:35). The API pre-fills estimated times on every pull; anything you type wins. Estimated times only show when they differ from the scheduled time. Overrides STA/STD in all emails and Teams posts.
Pax Count FieldEnter expected passenger count for the leg. Shown in the briefing card and carried into all emails and Teams posts. Counts also sync with the GateGadget pax store so gate teams see the same numbers.
Note FieldPer-leg freeform text (up to 100 characters). Appears italicized beneath the flight row. Shown in all emails and Teams posts. Use for ACARS notes, gate remarks, or crew status.
✗ Cancel CheckboxMarks a leg as cancelled — strikes through red, CXL badge appears. If both legs of a hardstand flight are cancelled, the card moves to the terminal section and is removed from HS exports.
✈ Gated ToggleCard-level toggle. When active, the card dims and all cells strike through, indicating the aircraft is blocked or on hold. The ✈ GATED indicator appears in the card header and in Teams posts.
Card CheckboxSelects the card for multi-card operations. When two or more cards are checked, a selection toolbar appears with ⎘ Email and 📤 Post to Teams for only those flights.
⚠ Gate/Pad Changed BadgeAmber badge when the API detects a reassignment since the baseline was set on first Generate. Hover the highlighted cell to see the original value in a tooltip.
🔴 +1 Next-Day BadgeRed badge on times that cross midnight — indicates the time belongs to the following calendar day. Auto-applied from the API's scheduled times.

4 — Running a Shift — Step by Step

1

Open TDOP & Choose Startup Option

If a saved briefing exists, the startup screen offers Load Saved (join today's shared state) or New Briefing (start clean — this erases the shared briefing for everyone, and TDOP asks you to confirm). Load Saved restores ETAs, notes, flags, and pax counts for every machine on the same day.

2

Set Date & Shift Time Window

Use the From and To date/time fields. If the date is locked, tap 🔒 Date to unlock it.

The window can cross midnight, for example 04:30 to 02:00 the next day.
3

Click ⟳ Refresh

Fetches live data from the Stand & Gate API through the Cloudflare Worker. Status dot pulses amber while loading, turns green on success. Left column: F-Hardstand operations. Right column: Terminal D gate flights.

4

Enter ETAs, ETDs, Notes & Pax

Click into the ETA/ETD cell, pax field, or note field on any leg. API estimates pre-fill automatically; whatever you type is kept on every 5-minute refresh.

5

Flag Cancellations & Gated Aircraft

Check ✗ on any cancelled leg (it strikes through red). Use ✈ Gated on a card when the aircraft is blocked or on hold. Add missing flights with + Add.

6

Save Your Work

Entries save automatically about 8 seconds after you stop typing (💾 Save forces an immediate save), and other machines see updates within 10 seconds.

7

Send Briefings & Post to Teams

Open ✉ Send Report ▾ for All Ops, HS Ops, LF Ops, Intl Ops, Traffic, F9 RONs, Sun Country AM Lineup, or NightBrief. Use 🚌 Bus Needed, 🚨 Alerts, or 👁 SeeSay for live Teams posts.

Intl Ops sends both email and a Teams card in one click.
8

Watch for Gate / Pad Changes

During auto-refresh, if a gate or pad is reassigned, the card gets an amber ⚠ badge and the cell highlights. Hover to see the original value. Baseline resets on Clear All and at 3:00 AM.

9

End of Shift — Clear All

Click 🗑 Clear All to wipe saved state, inputs, flags, and the gate-change baseline so the incoming coordinator starts clean. The app also resets itself at 3:00 AM.

6 — Tips, Notes & Good to Know

☁️
Cloud save & sync. Save and Load use shared cloud storage, so any machine or browser sees the same briefing. Entries auto-save about 8 seconds after you stop typing, a safety save runs every 30 minutes, and other machines check for updates every 10 seconds. If two people edit at once, the most recent save wins.
🔄
Auto-refresh & gate-change baseline. Data re-pulls every 5 minutes. The first pull captures every gate/pad as the baseline; later refreshes compare against it. New flights added mid-shift seed with no flag. Baseline resets on Clear All and at 3:00 AM.
🚌
BusBoard. After every successful refresh, the hardstand snapshot is published automatically for bus drivers. Flights that just moved from a hardstand to a gate stay visible for a few cycles so drivers see the transition. Terminal flights are never sent.
⏰
Nightly reset. At 3:00 AM local the saved state is wiped and a fresh briefing is pulled, so each shift day starts clean.
📋
Multi-select toolbar. Check two or more airline cards to Email or Post to Teams only those flights.
📅
Date lock. Once a briefing is pulled, the date locks to prevent accidental changes. Tap 🔒 Date to change it.
📡
Intl Ops. Sends email and a Teams card in one click. The Teams card appears as a flow bot post, not from your personal account.
🚨
Alerts. Blank fields on Alert I / II show as N/A on the card, so send as soon as you have the runway and callsign and follow up in chat. Header colors are Teams presets — amber (Alert I), red (Alert II), green (Terminated).
📋
Traffic. Uses the From / To times in the header, so set the window you want (for example 21:00–04:30 for overnight) before sending.
🌙
Dark mode. Manual toggle — does not follow OS settings. Night shift coordinators may prefer it in the gate environment.
🔧
EQUIP. Opens the equipment email form in its own tab so you can send a request without leaving your briefing.

7 — Future Enhancements — Roadmap

Features and improvements under consideration for future TDOP versions.

Operations
High Priority

☀️ SY Ops — Sun Country Summer Bus Ops

Dedicated SY Ops button for seasonal summer operations when Sun Country uses bus boarding at D5A/D5B. Would email dfwops@suncountry.com and Menzies SY contacts with a bus-gate scoped briefing card.

Notifications
High Priority

📲 Teams — All Ops Channel Post

Extend the Teams post pattern used by Intl Ops and Bus Needed to a full All Ops Teams post, sending the complete Terminal D briefing to a shared channel for supervisor review without opening email.

UX
Medium Priority

🕐 Shift Auto-Detection

Automatically detect the current shift (Mid / Day / Evening / Night) based on system time and pre-fill the shift time range on load, reducing clicks for coordinators at shift start.

Exports
Medium Priority

📋 Clipboard Copy for Email HTML

A "Copy HTML" option alongside each email send action so the formatted briefing card can be pasted directly into Outlook — useful on devices where mailto: links don't reliably open the mail client.

Operations
Medium Priority

🚌 D5A / D5B Split Bus Board

Update the Bus Board output to show D5A and D5B as two distinct rows, making clear which sub-gate each aircraft is assigned to. Currently both roll up to one D5 entry.

Future
Backlog

📱 Progressive Web App (PWA) Mode

Package TDOP as an installable PWA so coordinators can add it to their device home screen and access it with last-saved state, removing reliance on a browser bookmark.

Future
Backlog

🕑 Shift History Log

A read-only log of briefing sends during the current session — timestamp, action type, and recipient — so coordinators can confirm what was sent and to whom.

8 — Shift Start Checklist

1

Open TDOP. Choose Load Saved to continue today's shared briefing or New Briefing to start fresh.

2

Set the From / To window in the header. Tap 🔒 Date if the date is locked.

3

Click ⟳ Refresh. Wait for the status dot to turn green and the grid to populate.

4

Enter ETAs / ETDs — API estimates pre-fill; type over any that differ.

5

Add notes and pax counts, and flag cancellations with ✗ or ✈ Gated as needed.

6

Confirm your entries shared — they auto-save in about 8 seconds; click 💾 Save to force it.

7

Send briefings from ✉ Send Report ▾ — All Ops first, then scoped reports.

8

Monitor during shift — watch for ⚠ gate/pad change badges; use 🚌 Bus Needed and 🚨 Alerts for live Teams posts.

9

Use EQUIP for any ramp equipment issues that arise mid-shift.

10

End of shift: click 🗑 Clear All to reset for the incoming coordinator.

9 — How It Is Built (for Admins)

PieceWhat It Does
Netlify site (tdop)Hosts the TDOP page (index.html) and the guides. Updating the page means replacing the file in the GitHub repo or on Netlify and hard-refreshing the browser (Ctrl+Shift+R).
Cloudflare WorkerOne Worker handles three jobs. It forwards flight-data requests to the airport API and adds the stored API credential, so no password is in the page. It stores the shared briefing state (used by Save, Load and live sync). It stores the BusBoard snapshot. The page points at it through the WORKER_ORIGIN setting at the top of the script.
Worker settingsA KV namespace bound as TDOP_KV; a text variable UPSTREAM (the airport API host); and a secret UPSTREAM_AUTH (the API credential). Change the credential by updating the secret — no page edit needed.
Power Automate flowsSeparate Teams flows post the cards. Bus Needed (receives title, airline, from, to, posted), Alerts (one flow for Alert I, II and Terminated, switching on the kind field), SeeSay and Intl Ops. Each has its own link set near the top of the page script. If a Teams post fails, check that the flow is turned on and its Teams connection has not expired.
Card layoutsAlert and Bus Needed card layouts live inside each flow (Adaptive Card JSON), so you can change wording or rows without touching the page — just keep the field names (title, airline, from, to, runway, callsign, acType, issue, fob, sob, eta, posted, style, message).
GateGadget pax storePax counts entered in TDOP sync with the shared GateGadget store, so gate-side teams see the same numbers.
